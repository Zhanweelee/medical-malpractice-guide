# 疑似医疗事故应对 · 行动清单与答疑

一份供患者家属在诊疗出现严重异常时参考的行动资料，帮助推动救治、保存证据、协调转院，并逐项核对落实情况。

**[在线查看行动清单与答疑](https://zhanweelee.github.io/medical-malpractice-guide/)**

## 什么情况下使用

- 治疗过程中出现严重异常，需要跟进急救、会诊和后续治疗安排。
- 需要及时取得病历，保存和封存相关实物、监控等证据。
- 治疗效果不佳或恢复缓慢，需要向院方提出转院申请、协调接收医院和安全转运。
- 提交申请或保存证据遇到阻力，需要查找下一步可以采取的行动。

## 包含哪些内容

| 内容 | 可以参考什么 |
| --- | --- |
| 11 项行动清单 | 具体怎么做、先做什么，以及怎样核对是否完成 |
| 13 条常见答疑 | 病历暂不给打印、监控查看受阻、封存未落实、转院文件含免责表述等情况如何推进 |
| 2 份书面申请模板 | 救治协调与证据保存申请、转院协调与安全转运申请 |
| 封存核对清单 | 病历、现场实物和监控视频需要记录的范围、数量、保管人及其他字段 |
| 参考依据 | 可用于核对相关要求的官方文件 |

## 怎么使用

打开在线清单，按现场情况分工处理，核对每项的“完成判断”后再勾选。有疑问时，在顶部搜索“病历”“监控”“转院”等关键词，点击结果查看对应内容。申请模板需要根据实际事实修改后使用。

清单进度只保存在当前浏览器，页面不收集患者信息。可以打印或保存为 PDF，供家属共同核对。

救治优先，留证并行。新增资料和病情变化仍需持续跟进；具体诊疗、转运和案件处理应结合实际情况及专业意见，不要因文书争议延误必要救治。
